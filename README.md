## 🗡️ What is SleeperBuild?

**SleeperBuild** (`com.sleeper.build7`) ek high-performance, privacy-first offline Android discipline app hai jisko single goal ke saath craft kiya gaya hai: **relentless self-improvement**. 

Yeh app aapke daily routine ke core pillars ko regulate karta hai — Spiritual alignment (Prayer times), Physical conditioning (BMI & Workouts), Daily scheduling (Study & Timers), Mental fortitude (No Fap & No Smoke tracking), aur Daily Journaling (Daily Gains).

Aapka poora identity aur progress data **100% locally encrypted** rehta hai. Isme na koi tracking hai, na backend spying — sirf Pure Code, Custom Shaders, aur Beast Mode logic.

---

## 🔥 Key Modules & Features

### 🕌 1. Prayer Module (Automated & Location-Aware)
- **Location-Based Accuracy**: GPS coordinates use karke 5 daily Islamic Prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha) REST API se fetch karta hai.
- **Smart System Alarms**: Auto-schedules system alarms 5 minutes prior to every prayer. `BroadcastReceiver` support ke sath device reboot hone par bhi alarm scheduling skip nahi hoti.
- **History Audit**: Daily tick-list for completed prayers, historical calendar view ke sath self-consistency check karne ke liye.

---

### ⚔️ 2. Workout & BMI Engine (Gamified Physical Progress)
- **Adaptive BMI Guidance**: Daily weight/height calculate karke personalized target training rules deta hai.
- **3 Equipment Modes**: Bodyweight, Simple Equipment, Full Equipment.
- **Floating Music Launcher**: Screen par float karta hua action button jisko single tap karke aap custom music/audio apps launch kar sakte ho. (Long-press to update target package name).
- **Rank-Up System**: Progressive scaling system jo human limits ke according daily set counts (Push-ups, Pull-ups, Chin-ups) update karta hai.

---

### ⏱️ 3. Schedules Module ("Study & Others")
- **Multi-Session Timers**: Flexible interval study timers precise background system clock integration ke sath.
- **Custom TTS Engine**: Standard system alarms ki jagah custom text-to-speech engine speech trigger karta hai.
- **Dual Voice Models**: 
  - 👧 **Cute Girl Voice**: Higher pitch (~1.35x), energetic flow.
  - 👦 **Cute Boy Voice**: Balanced pitch (~0.9x), crisp & authoritative tone.

---

### 📝 4. Daily Gains (Markdown Notes + Media Gallery)
- **Build Logs**: Apne daily achievements, software modding projects, web updates, aur coding breakthroughs ko log karo.
- **Rich Markdown Support**: Live syntax preview, image URIs, video URIs, aur voice attachments support.
- **Glass Gallery UI**: Frosted-glass grid layout me aapke micro-wins surface hote hain.

---

### 🔞 5. No Fap (Mental Fortitude Tracker)
- **Streak Engine**: Days passed counter with dynamic ranking tiers based on abstinence longevity.
- **Emergency Reset**: Relapse toggle triggering motivational quotes, immediate stats logging, and day count reset.

---

### 🫁 6. No Smoke (Dual Angelic / Demonic Canvas Engine)
Screen toggle me ek special **Uno Reverse** button integrated hai to switch states:
- 🪽 **Angelic Mode (No-Smoke Tracker)**: Material You light gradient with custom Canvas-rendered **Breathing Healthy Lungs** animation. Cigarette visual gradually fades out as your non-smoking streak grows.
- 👿 **Demonic Mode (Active Smoke Counter)**: Dark obsidian theme featuring **Burning Flame Lungs** canvas animations (Ghost Rider style). Fire rays aur smoke density surge hoti hai with every logged cigarette. *Counter stats never reset.*

---

### 🛡️ 7. Security Architecture & Encrypted Backups
- **Triple-Lock Security**: Dynamic configuration between **PIN**, **Password**, or **Pattern Drawing Lock**.
- **Granular Lock Scopes**: App-level startup lock or individual section locks (*No Fap*, *Daily Gains*, etc.).
- **PIN-Encrypted JSON Backup**: Full state JSON export/import encrypted with a secret user PIN. Zero data loss if app data is cleared.

## 🛠️ Tech Stack & Architecture

```text
SleeperBuild / com.sleeper.build7
 ├── Jetpack Compose (Declarative UI Architecture)
 ├── Material 3 (Dynamic Color & System-based Adaptive Theme)
 ├── Canvas Rendering Engine (Procedural Lungs & Smoke Particle Systems)
 ├── TextToSpeech Engine (Custom Dynamic Voice Pitch Modulation)
 ├── System AlarmManager + BroadcastReceivers (Background Persistence)
 └── EncryptedSharedPreferences (Hardware-backed AES-256 Local Storage)
```

| Component | Implementation |
| :--- | :--- |
| **Language** | Kotlin 100% |
| **UI Framework** | Jetpack Compose + Material You Dynamic Color |
| **Design Language** | Glassmorphic Translucent Panels + Dynamic Canvas Shaders |
| **Persistence** | `EncryptedSharedPreferences` / GSON Serialization |
| **Location / Network** | Android Location Provider + REST Prayer API |
| **Architecture** | Single Activity Architecture (`MainActivity.kt`) |
